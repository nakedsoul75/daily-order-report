# 주방 동선·배치 레퍼런스 — 한식·카페·일식 업종별 설계 자료

> 특정 업종(한식, 카페·베이커리, 일식·스시) 주방의 **동선(circulation)**, **주방 흐름(work flow)**, **배치 조합(layout)**에 대한 전문가 자료·학술 논문·실무 가이드를 정리한 문서입니다.
> 조사 출처: 네이버 학술자료 / 전문 도서 / 외식 인테리어 실무 블로그 (2026-05 기준).

---

## 1. 모든 상업주방에 공통되는 설계 원칙

업종을 막론하고 상업주방 배치는 아래 4가지 원칙 위에서 결정됩니다. 업종별 차이는 이 원칙을 "어떤 작업에 가중치를 두느냐"의 차이입니다.

### 1.1 단방향 흐름 (One-way / Linear Flow)
식자재가 한 방향으로만 이동하도록 배치해 역류·교차를 막습니다.

```
입고 → 검수 → 저장(냉장/냉동/건자재) → 전처리 → 조리 → 담음(플레이팅) → 서빙(픽업) → 퇴식/세척
```

- 입고구와 퇴식·세척 동선이 겹치면 **교차오염**과 동선 충돌이 발생합니다.
- 세척을 마친 그릇은 다시 담음·조리 구역으로 "깨끗한 동선"을 타고 돌아갑니다.

### 1.2 작업 삼각형 (Work Triangle)
**냉장고(저장) — 싱크대(세척/전처리) — 가열대(조리)** 세 점을 잇는 삼각형. 가정·소형 주방 동선의 기본 모델입니다.

- 세 변의 합은 일반적으로 **3.6m~6.6m** 권장(너무 짧으면 혼잡, 너무 길면 피로).
- 한 변의 거리는 **1.2m~2.7m**가 적정. 작업 동선 위에 통행 동선이 가로지르지 않도록 합니다.
- 상업주방·다인 운영에서는 단일 삼각형 대신 **작업 구역(zone)별 스테이션** 개념으로 확장합니다.

### 1.3 청결구역 / 오염구역 분리
- **오염구역**: 입고·검수·전처리·세척(퇴식). 물·이물·생식자재가 모이는 곳.
- **청결구역**: 조리·담음·배식. 가열 후 식품이 노출되는 곳.
- 두 구역 사이에 **위생전실(손세정·환복)**, 물리적 가벽, 또는 최소한의 거리·동선 구분을 둡니다(HACCP 선행요건).
- **인적 동선(사람)**과 **물적 동선(식자재·식기)**도 가능하면 분리합니다.

### 1.4 통로 폭(클리어런스) 기준 (실무 권장치)
| 구분 | 권장 폭 |
|---|---|
| 1인 통행 작업 통로 | 0.9m ~ 1.0m |
| 2인 교행 / 조리대 뒤 작업 통로 | 1.2m ~ 1.5m |
| 카트·대차 통행 | 1.5m 이상 |
| 오픈도어(냉장고/오븐) 앞 여유 | 도어 깊이 + 0.6m |

## 2. 주방 레이아웃 기본 유형

| 유형 | 형태 | 특징 / 적합 업종 |
|---|---|---|
| **일자형 (一/I-line)** | 한쪽 벽면에 일렬 배치 | 초소형·협소 공간, 1인 운영 카페·테이크아웃. 동선 짧음, 작업면 부족 |
| **병렬형(11자/갤리, Galley)** | 마주보는 두 줄 | 좁고 긴 공간에서 면적 효율 최고. 단방향 흐름과 궁합 좋음. 분식·소형 일식·바(bar) |
| **ㄱ자형 (L-shape)** | 인접한 두 벽 | 작업 삼각형 구현 쉬움, 코너 활용. 중소형 카페·다이닝 |
| **ㄷ자형 (U-shape)** | 세 벽 둘러쌈 | 작업면·수납 최대, 1~2인이 중심에서 모든 작업 접근. 한식 단독주방, 스시 다찌 |
| **아일랜드/섬형 (Island)** | 독립 조리섬 | 오픈키친, 사방 접근. 대형 주방·오픈 다이닝. 환기·배기 설계가 핵심 |

> 소형 카페/분식점은 동선 길이를 줄이는 **원형(360°) 동선**(좁은 ㄷ/병렬)이, 회전율 높은 주방은 **단방향 라인형**이 유리합니다.

## 3. 업종별 동선·배치 조합

### 3.1 한식 주방 (Korean / 한식당·설렁탕·백반·고기구이)

**특성**
- 국·탕·찌개 등 **대용량 화구·육수솥** 비중이 큼 → 가열대·배수·배기 부하가 높음.
- 반찬(찬류) 다품목 → **콜드 스테이션(냉장 반찬고)**과 담음 공간이 별도로 필요.
- 직화구이(생선구이·고깃집)는 **연기·냄새 배기 설계**가 일반 한식당과 다름(별도 후드·덕트).
- 밥솥·취반 라인, 김치·장류 저장(냉장) 공간.

**권장 배치 조합**
- 가열 라인(육수솥·렌지)을 **벽면 일자/ㄷ자**로 모아 배기 후드 아래 집중.
- 전처리(채소·육류) → 가열 → 담음(반찬+밥+국) → 픽업패스 순으로 **단방향**.
- 홀 서빙 동선과 퇴식 동선을 분리(반찬 리필 동선이 짧아야 함).
- 바닥은 배수가 많아 **트렌치(집수정) 구배** 필수, 습식 주방 전제.

**참고 자료**

- 학술: *외식업의 근무환경이 업무효율 및 서비스 품질에 미치는 영향* (한식당 중심). https://academic.naver.com/article.naver?doc_id=45318828
- 실무: 백숙집·생선구이 등 한식당 단독주방 설계 시공 사례
  - 스틸웍스 (백숙집 단독건물 한식주방 설계): https://blog.naver.com/stillworks/224171088595

### 3.2 카페 / 베이커리 카페 (Cafe / Bakery)

**특성**
- 핵심은 **바(bar) 동선**: 주문(POS) → 추출(에스프레소 머신·그라인더) → 제조(스팀·블렌더) → 픽업.
- 그라인더는 머신 바로 옆, 추출 직후 **피처 린서(pitcher rinser)**·넉박스 위치가 동선을 좌우.
- 1인~2인 바리스타 운영이 많아 **반보(half-step) 동선** 설계가 매출·인건비에 직결.
- 베이커리 겸업 시 **제빵존(오븐·발효·작업대)**과 음료존을 분리하되, 쇼케이스·픽업은 통합.

**권장 배치 조합**
- 카운터는 입구 정면, 고객 시선·대기열과 바리스타 동선을 분리.
- 음료 바: **병렬(11자)** 또는 **ㄷ자** — 한 발 안에서 머신·그라인더·제빙기·온수·픽업이 닿게.
- 머신/그라인더/온수기/제빙기를 **추출 흐름 순서**대로 직선 배치, 세척(린서·싱크)은 추출부 인접.
- 베이커리: 냉장(재료) → 작업대(반죽·성형) → 발효 → 오븐 → 냉각·진열 단방향. 오븐 배기·열 분리.

**참고 자료**
- 실무: *카페 주방 동선 설계 추천, 머신·그라인더 배치 팁* (아프니까 사장이다 발품맨). https://blog.naver.com/poopoo3939/223728701265
- 실무: *베이커리 카페 주방 설계 — 작업 동선부터 장비 배치까지* (배베스토리). https://blog.naver.com/baebe_story/223760487101
- 실무: *10평 카페 동선 설계 — 매출과 인건비를 바꾸는 배치법* (과정의온도 인테리어PM). https://blog.naver.com/pm_interior/224271674551

### 3.3 일식 / 스시·오마카세 (Japanese / Sushi·Omakase·Izakaya)

**특성**
- **다찌(가운터/付け台)** 중심: 셰프가 손님 앞에서 조리·제공하므로 **주방=무대**. 청결·정돈이 동선 설계의 일부.
- 셰프 1인 운영이 많아 **닷지(다찌) 안쪽 작업공간 + 메인 주방** 이원 구조로 동선 최소화.
- 생선 전처리(생물 취급)·냉장 비중이 높아 **콜드 체인**과 칼·도마 위생 동선 중요.
- 이자카야는 튀김·구이·사시미 등 **다(多)조리법** → 스테이션 분리.

**권장 배치 조합**
- 오마카세: **주방 + 아일랜드(작업대) + 카운터(다찌)를 하나의 영역**으로 묶어 제공자 동선 최소화.
- 다찌 안쪽엔 즉석 작업(샤리·네타 손질), 무거운 작업·세척은 후방 메인주방으로 분리 → 동선 효율↑.
- 오픈주방 + 다찌 구조로 1인 운영 시 회전·집중 동선 확보.
- 사시미·초밥은 청결구역, 생선 전처리·세척은 오염구역으로 명확히 구분.

**참고 자료**
- 학술: *외식업 창업을 위한 식공간 디자인 가이드라인 개발 연구 — 일식 이자카야* (창업용 식공간 가이드라인). https://academic.naver.com/article.naver?doc_id=964440943
- 실무: *공간의 일식당 — 주방·아일랜드·카운터를 하나의 영역으로 설계* (이음랩). https://blog.naver.com/heiio235/224078574815
- 실무: *25평 스시 전문점 다찌형 — 메인주방+다찌 안쪽 분리 동선* (부콘). https://blog.naver.com/kkkkk0369/224293538085
- 실무: *고급 오마카세 인테리어 — 조리대 수납·소통 동선* (디투엠). https://blog.naver.com/d2m-master/223946717496

## 4. 위생·법규 기반 동선 (HACCP / 청결·오염 구역)

오픈주방·프랜차이즈·납품 겸업 시 반드시 검토.

- **구역 분리**: 일반(오염)구역과 청결구역을 물리적 가벽으로 분리, 사이에 **위생전실**(손세정·에어샤워·환복) 배치.
- **단방향 공정**: 입고 → 해동/전처리 → 작업 → 포장/담음 → 출고. 입고와 출고가 엇갈리면 교차오염 입증이 복잡.
- **인적·물적 동선 분리**: 작업자 동선과 식자재·식기 동선을 나눔.
- **Dry Kitchen 개념**: 바닥을 건식으로 유지해 미생물 번식·낙상 위험 저감(학교급식·대량조리 시설 모델에서 채택).

**참고 자료**
- 학술: *학교급식 위생수준 향상을 위한 HACCP·Dry kitchen 개념 적용 시설 모델*. https://academic.naver.com/article.naver?doc_id=175092722
- 학술: *외식산업 주방관리시스템의 효율적인 개선에 관한 연구*. https://academic.naver.com/article.naver?doc_id=890454770
- 학술: *센트럴 키친 시스템이 가맹점 주방업무 효율성·만족도에 미치는 영향*. https://academic.naver.com/article.naver?doc_id=175123527
- 실무: *HACCP 청결구역은 어떻게 만들어지나 — 동선 분리·위생전실*. https://blog.naver.com/rare1325/224293466945
- 실무: *청결구역/일반구역 분리 및 위생전실 위치* (노원행정사). https://blog.naver.com/war_weaver/223816262362
