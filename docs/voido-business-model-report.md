## ■ Executive Summary (1페이지 요약)

### 한 줄 정의
> **"강제성 없는 어필리에이트 + 자체 제조 원가 우위 + 점주 풀 기반 협상력 플라이휠"** 사업 모델

### 사업 본질
한국 프랜차이즈 본사 모델의 **검증된 성공 방정식**을 차용하되, **강제성을 제거**하여 가맹사업법 리스크를 회피하고, **자체 제조 원가 우위**(팩토리나인)와 **영천 제조 공장+쇼륨 라인투어+사옥 쇼륨**을 차별화 무기로(신뢰성 업) 활용하는 토털 패키지 창업 지원 모델

### 핵심 제안 가치
1. **고객(점주)**: 인테리어 30% 할인 + 토털(인테리어+주방 집기+테이블류) 패키지 원스톱 서비스
2. **협력사**: 디엘나인의 점주 접점 제공 → 영업 성공율 상승, 영업 시, 최 선단 단계에서 점주 접점 제공
3. **디엘나인**: 자체 부족 영업 조직 약점 회피 + 인프라 수수료 누적 + 협력사 네트워크 확장 + 지속 마진 확보

### 핵심 의사결정 사항
1. Phase 1 (대구·경북) 파일럿 추진 여부
2. 변호사 자문(가맹사업법) 진행 승인
3. DL 라인 팩토리 공급 받는 제품류 마진 정책 변경 (100% → 70%) 승인
4. 전체 마진 구조 분석 시트 필요
   - 4.1 팩토리 공급 받는 부분: 30% 마진 (주방 및 집기류, 간판 포함하여 전체 30%)
   - 4.2 시공 마진: 유지
   - 4.3 자재 부분: 마진 유지

## 1. 사업 배경 및 문제 정의

### 1.1 시장 환경
- 한국 외식·소매업 창업 시장은 **연 50~70만 건 규모**
- 창업 시 인테리어 → 인프라(POS 단말기, 카드 연동, 인터넷, 정수기, 테이블 오더, 배달로봇, 온라인 및 지역 광고 등) 일체 인프라 제공 및 계약 수주
- 각 단계마다 **별도 업체와 개별 계약** → 점주 입장 피로도 ↑
- 인테리어 시장은 **거품(40~50% 마진)** 이 만연

### 1.2 디엘나인의 현재 상황
- **강점**: 자체 제조 역량(팩토리나인), 영천 사옥 보유, 개발·마케팅 조직
- **약점**: 자체 영업조직이 작음 → 매출 확장이 영업력에 묶임
- **기회**: 인테리어 진입을 통해 창업 시발점 선점 가능
- **위협**: 기존 프랜차이즈 본사 모델과의 경쟁, 가맹사업법 규제, 카테고리 확장으로 관리 및 구조 다소 복잡

### 1.3 본 모델이 해결하는 문제
1. **점주 측**: "각 인프라 계약을 매번 따로 하기 번거롭다" → 토털 패키지로 해결
2. **디엘나인 측**: "영업조직이 작아 매출 확장이 어렵다" → 협력사 영업력 외주화로 해결
3. **협력사 측**: "신규 점주 접근 비용이 크다" → 디엘나인 접점을 통해 절감 + 영업 성공율 상승 기대

## 2. 비즈니스 모델 상세

### 2.1 진입 전략 (Trojan Horse)
- **자체 제조 제품 (철제가구 등)** 을 마진 일부분 포기한 저렴한 단가 제공
- 인테리어 시공: **예시) 타사 1,000만원 → Voido 700만원** (30% 할인)
- 점주가 "이건 진짜 싸다"라고 체감하는 메리트 제공
- 메시지: **"최소 공장 마진까지 빼고 판다"** + "풀 페키지이기 때문에 제공 가능한 구조"

### 2.2 마진 구조 재설계

| 사업 라인 | 기존 마진 | 신규 마진 | 변경 이유 |
| --- | --- | --- | --- |
| **팩토리나인** (자체 제조) | 정상 마진 | **이익 보존** | 원가 우위 유지 |
| **DL Nine** | 100% 마진 확보 | **30%만** | 시장 거품 회수 + 파이 확대 |
| **인프라 수수료** | 0% | 0.5%~1% 누적 | 신규 수익원 |
| 인프라 초기 계약 수수료 | 0% | 300만원/건 - 정확한 수치 계산 필요 | 신규 수익원 |

**핵심 논리**: 인테리어 시장에는 거품이 많으므로 우리가 마진을 양보해도 시장 평균 이하 가격을 만들 수 있고, 양보분은 점주 혜택 + 파이 확대로 전환된다.

### 2.3 인프라 수익원 (점주 1명당 추정 — 실 현업 영업 담당자와 숫자 확인 필요)

| 항목 | 수익 구조 | 월 예상 수익 |
| --- | --- | --- |
| 카드 단말기 | 거래액의 0.0X% × 수년 | 매출 5천만 기준 월 2~5만원 |
| 인터넷 구독 | 계약 수수료 + 월 리베이트 | 월 1~2만원 |
| 정수기 렌탈 | 렌탈료의 0.5% | 월 1천~3천원 |
| 테이블오더 | 설치비 + 월 사용료 리베이트 | 월 3~10만원 |
| 배민 광고/깃발 | 광고비 0.5% | 월 2~5만원 |
| **합계** |  | **월 6~16만원** |
| 일회성 수수료 |  | 300~500만원 |

**누적 회수 시뮬레이션**
- 연 환산: 70~190만원

### 2.4 운영 분담 구조 (50:50)
- **디엘나인 역할 (50%)**:
  - 리드 발굴 (인테리어 진입 시점에 패키지 제안)
  - 패키지 큐레이션 (어떤 협력사를 묶을지 결정)
  - 점주 신뢰 확보 (쇼룸 투어, 통합 견적)
- **협력사 역할 (50%)**:
  - 실제 클로징 (정수기 업체가 직접 방문 상담)
  - 설치 및 사후 CS
  - 디엘나인에 수수료 정산

**핵심**: 디엘나인은 **B2B 어필리에이트 포지션**으로 인건비·전문성 부담 최소화

### 2.5 영업 조직 외주화 (핵심 혁신)

**문제 인식**:
- 디엘나인은 개발·마케팅 중심
- 자체 영업조직 운영 시 인건비 부담 큼

**해결책**:
1. **협력사 영업조직 자발적 유입**
   - 배민·정수기·POS·로봇·인터넷 등 각 분야 영업조직 보유
   - 디엘나인이 "창업 시발점 접점"을 제공 → 협력사 입장에서 매력적
   - 협력사가 자발적으로 협력 제안 들고 옴

2. **지역 영업맨 포섭**
   - 각 광역시별 우수 영업맨 1~2명에게 수수료 룰 제공
   - 영업맨이 신규 점주 발굴 → 디엘나인이 패키지 매칭 → 수수료 분배
   - 영업맨 입장: 토털 패키지를 무기로 영업 가능 (혼자 영업할 때보다 성공률 ↑)

3. **수수료 룰 설계 (예시)**
   - 영업맨 신규 발굴 점주: 첫 12개월 수수료의 50% 영업맨, 이후 20%
   - 점주 계약 주체는 **디엘나인**으로 설정 (영업맨이 점주 빼가기 방지)

**결과**: 자체 영업조직 채용·운영 비용 0원으로 다채널 영업망 구축

### 2.6 신뢰 구축 메커니즘

1. **영천 창대 공장+사옥 = 실물 쇼룸**
   - 점주 후보 직접 투어
   - "실체 있는 회사"임을 증명
   - 의심 차단 ("왜 이렇게 싸게 해주지?" + "망하면 어떻하지?" → 자체 제조라 가능 + 토탈 패키지로 네고 가능 룸 발생)

2. **강제성 제거**
   - "의심스러우면 우리거 안 해도 된다"
   - 옵셔널 구조로 압박감 없음
   - 가맹사업법·공정거래법 회피

3. **시장가 동일 가격**
   - 인프라 항목(카드·정수기 등)은 시장가로 제공
   - 추가 마진을 점주에게 부과하지 않음
   - 수수료는 협력사가 디엘나인에 지급 (점주 부담 없음)

## 3. 핵심 강점 (Competitive Advantages)

### 3.1 자원 효율성 (가장 큰 강점)
- 자체 영업조직 0원
- 협력사·지역 영업맨이 영업 수행
- 디엘나인은 접점 큐레이션에 집중
- **소기업이 전문 프렌차이즈 모델을 모방 가능한 구조**

### 3.2 검증된 패턴 차용
- 한국 프랜차이즈 본사 모델 = 이미 작동 확인된 구조
- 신규 시장 개척 리스크 없음
- 강제성 제거로 법적 회색지대 회피 가능

### 3.3 자체 제조 원가 우위 (진짜 해자)
- 철제가구 자체 제조 = **경쟁사 모방 불가능**
- 팩토리나인 이익 보존 + DL 마진 양보 = 시장 가격 파괴 가능
- 디엘나인만의 **유일무이한 차별점**

### 3.4 플라이휠 효과 (점주 풀 기반 협상력)
```
   점주 풀 확보 → 대기업 직접 채널 → 수수료율 인상
        ↑                                        ↓
   역인바운드 영업 ← 시장 소문 ← 더 좋은 조건으로 점주 유치
```
- **초기 (점주 1~30명)**: 협력사 마진의 0.5%
- **중기 (점주 30~100명)**: 0.7% 협상 가능
- **장기 (점주 100명+)**: **1% 이상 + 대기업 직접 코드**
- **궁극**: 배민·로봇업체·POS업체가 **먼저 찾아옴** (역인바운드)

### 3.5 토털 패키지 = 진입 시점 선점
- 인테리어 = 모든 창업의 **시발점**
- 인테리어 완공 후 영업 ❌ → 처음부터 토털 패키지 ✅
- 제공 범위·선택권·가격 결정권을 디엘나인이 보유

### 4.2 "강제성 없는 인테리어 중심 토털 패키지"가 드문 이유
1. 인테리어 1회성 → 반복 매출 모델과 궁합 불일치
2. F&B 폐업률이 LTV 파괴
3. 인테리어는 지역밀착 산업 → 표준화 어려움
4. 결국 프랜차이즈 본사로 수렴 (가맹사업법 진입)

### 4.3 결론
> "없으니까 블루오션"이 아니라, **디엘나인은 자체 제조 원가 우위 + 옵셔널 구조라는 한국 시장 맞춤형 변형**으로 틈새 공략 가능
