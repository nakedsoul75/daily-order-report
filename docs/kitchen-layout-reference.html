1. 모든 상업주방의 공통 설계 원칙

업종 차이는 아래 원칙 중 어느 작업에 가중치를 두느냐의 차이입니다.

1.1 단방향 흐름 (One-way Flow)

식자재가 한 방향으로만 이동하도록 배치해 역류·교차오염을 방지합니다.

입고→ 검수→ 저장(냉장/냉동/건자재)→ 전처리→ 조리→ 담음→ 서빙(픽업)→ 퇴식·세척

입고구와 퇴식·세척 동선이 겹치면 동선 충돌·교차오염 발생. 세척 완료 식기는 "깨끗한 동선"으로 담음·조리 구역에 복귀.

1.2 작업 삼각형 (Work Triangle)

냉장고(저장) — 싱크대(세척/전처리) — 가열대(조리) 세 점을 잇는 삼각형. 소형 주방 동선의 기본 모델.

  • 세 변의 합 3.6m~6.6m 권장 (짧으면 혼잡, 길면 피로)
  • 한 변 1.2m~2.7m 적정. 작업 동선 위로 통행 동선이 가로지르지 않게
  • 다인 운영·상업주방은 단일 삼각형 대신 구역(zone)별 스테이션으로 확장

1.3 청결구역 / 오염구역 분리

구분포함 작업특징
오염구역입고·검수·전처리·세척(퇴식)물·이물·생식자재가 모이는 곳
청결구역조리·담음·배식가열 후 식품이 노출되는 곳

두 구역 사이에 위생전실(손세정·환복)·가벽·거리 구분을 두고, 인적 동선(사람)과 물적 동선(식자재·식기)도 가능하면 분리.

1.4 통로 폭(클리어런스) 실무 권장치

구분권장 폭
1인 통행 작업 통로0.9m ~ 1.0m
2인 교행 / 조리대 뒤 작업 통로1.2m ~ 1.5m
카트·대차 통행1.5m 이상
냉장고·오븐 도어 앞 여유도어 깊이 + 0.6m

2. 주방 레이아웃 기본 유형

유형형태특징 / 적합 업종
일자형 (一/I)한 벽면 일렬초소형·1인 운영 카페·테이크아웃. 동선 짧음, 작업면 부족
병렬형 (11자/갤리)마주보는 두 줄좁고 긴 공간 면적효율 최고. 단방향 흐름과 궁합 좋음. 분식·소형 일식·바
ㄱ자형 (L)인접한 두 벽작업 삼각형 구현 쉬움, 코너 활용. 중소형 카페·다이닝
ㄷ자형 (U)세 벽 둘러쌈작업면·수납 최대, 중심에서 모든 작업 접근. 한식 단독주방·스시 다찌
아일랜드/섬형독립 조리섬오픈키친·대형 주방. 사방 접근. 환기·배기 설계가 핵심
소형 카페·분식점은 동선을 줄이는 원형(360°) 동선(좁은 ㄷ/병렬)이, 회전율 높은 주방은 단방향 라인형이 유리.

한식  3-1. 한식당 · 설렁탕 · 백반 · 고기구이

특성

  • 국·탕·찌개 등 대용량 화구·육수솥 비중 큼 → 가열대·배수·배기 부하 높음
  • 반찬 다품목 → 콜드 스테이션(냉장 반찬고)·담음 공간 별도 필요
  • 직화구이(생선·고기)는 연기·냄새 배기 설계가 일반 한식당과 다름(별도 후드·덕트)
  • 밥솥·취반 라인, 김치·장류 저장(냉장)

권장 배치 조합

  • 가열 라인(육수솥·렌지)을 벽면 일자/ㄷ자로 모아 배기 후드 아래 집중
  • 전처리 → 가열 → 담음(반찬+밥+국) → 픽업패스 단방향
  • 홀 서빙 동선과 퇴식 동선 분리(반찬 리필 동선 짧게)
  • 배수 많은 습식 주방 전제 → 바닥 트렌치(집수정) 구배 필수

카페  3-2. 카페 · 베이커리 카페

특성

  • 핵심은 바(bar) 동선: 주문(POS) → 추출(머신·그라인더) → 제조(스팀·블렌더) → 픽업
  • 그라인더는 머신 옆, 추출 직후 피처 린서·넉박스 위치가 동선을 좌우
  • 1~2인 바리스타 운영 → 반보(half-step) 동선이 매출·인건비에 직결
  • 베이커리 겸업 시 제빵존(오븐·발효·작업대)과 음료존 분리, 쇼케이스·픽업은 통합

권장 배치 조합

주문 POS→ 그라인더→ 에스프레소 머신→ 스팀·제조→ 린서·세척→ 픽업
  • 카운터는 입구 정면, 고객 대기열과 바리스타 동선 분리
  • 음료 바: 병렬(11자) 또는 ㄷ자 — 한 발 안에서 머신·그라인더·제빙기·온수·픽업 닿게
  • 베이커리: 냉장(재료) → 작업대(반죽·성형) → 발효 → 오븐 → 냉각·진열 단방향, 오븐 열·배기 분리

일식  3-3. 일식 · 스시 · 오마카세 · 이자카야

특성

  • 다찌(카운터/付け台) 중심: 셰프가 손님 앞에서 조리 → 주방=무대. 청결·정돈이 동선 설계의 일부
  • 셰프 1인 운영 많음 → 다찌 안쪽 작업공간 + 후방 메인주방 이원 구조로 동선 최소화
  • 생선 전처리(생물)·냉장 비중 높음 → 콜드 체인·칼·도마 위생 동선 중요
  • 이자카야는 튀김·구이·사시미 등 다(多)조리법 → 스테이션 분리

권장 배치 조합

  • 오마카세: 주방 + 아일랜드(작업대) + 카운터(다찌)를 하나의 영역으로 묶어 제공자 동선 최소화
  • 다찌 안쪽엔 즉석 작업(샤리·네타 손질), 무거운 작업·세척은 후방 메인주방으로 분리
  • 오픈주방+다찌 구조로 1인 운영 시 집중 동선 확보
  • 사시미·초밥(청결구역)과 생선 전처리·세척(오염구역) 명확히 구분

4. 위생·법규 기반 동선 (HACCP)

오픈주방·프랜차이즈·납품 겸업 시 필수 검토.

  • 구역 분리: 일반(오염)/청결구역을 가벽으로 분리, 사이에 위생전실(손세정·에어샤워·환복)
  • 단방향 공정: 입고 → 해동/전처리 → 작업 → 포장/담음 → 출고. 입고·출고 엇갈리면 교차오염 입증 복잡
  • 인적·물적 동선 분리: 작업자 동선과 식자재·식기 동선 분리
  • Dry Kitchen: 바닥 건식 유지 → 미생물·낙상 위험 저감(학교급식·대량조리 모델)
