## 1. 비즈니스 모델 개요

### 핵심 컨셉
**"인테리어 미끼상품 + 토털 패키지 부가수익"** 구조의 창업 지원 통합 솔루션

### 1.1 진입 전략 (미끼상품)
- Voido에서 제작·판매하는 **철제 가구 및 모든 제품**을 마진 최소화로 제공
- 세일즈 시점에 **"채소공장 마진까지 빼고 판다"** 메시지로 접근
- **인테리어 시공 가격**: 타사 1,000만원 → Voido 600~700만원 (30~40% 할인)
- 고객(창업자/프랜차이즈 후보)이 체감적으로 큰 메리트를 느끼는 구조

### 1.2 수익 보전 구조 (적립형 인프라 매출)
저렴한 인테리어로 빠지는 영업이익을 다음 인프라 중개 수수료로 보전:
- 인터넷 구독
- 카드 단말기
- 광고 대행
- 배민 깃발 꽂기 (자체 영업사원 수행)
- 정수기 등 기타 인프라

→ **고객에게는 시장가 그대로 제공** (추가 마진 없음, 신뢰 확보)

### 1.3 신뢰 구축 장치
- 영천 창대 사옥 = 쇼룸으로 활용
- 콤마나인 사옥 투어를 통해 **실체 있는 회사**임을 증명
- "왜 이렇게 싸게 해주지?" 의심·반발감 사전 차단

### 1.4 영업 조직 없이 협업 모델
- 별도 영업 조직 구축 불필요
- 기존 영업 조직 보유 업체와 협업
  - 배민 영업사원 유입 가능
  - 정수기 업체와 협업: 직접 영업 시 마진 1% → Voido 소개 시 0.5%
- 핵심: **인테리어가 모든 창업의 시발점**이므로 초기 진입 우위 확보

## 2. 구조적 약점 및 리스크

### 2.1 단위경제(Unit Economics)의 함정
- 인테리어 할인폭 30~40%는 일반 인테리어 업체 영업이익률(10~15%)을 **상회**
- 즉 "마진을 줄이는" 게 아니라 **원가 이하 또는 손익분기점 아래** 진입
- 인프라 수수료 회수 시뮬레이션 (추정):
  - 카드단말기·인터넷: 월 1~3만원
  - 정수기: 월 1,000~3,000원
  - 배민 깃발/광고: 월 2~5만원
  - **월 평균 5~10만원 적립이 현실적**
  - **300~400만원 적자 회수에 3~6년 필요**

### 2.2 F&B 폐업률이라는 치명적 변수
- 국내 외식업 **3년 내 폐업률 약 50~60%** (통계청 기준)
- 고객이 3년 안에 망하면 인테리어 적자만 남고 회수 불가
- **LTV(고객생애가치) 계산이 사실상 도박**

### 2.3 "마진 안 받는다" 메시지의 모순
- 카드단말기·정수기·배민 광고를 시장가로 제공하면서 수수료(0.5%, 코드 발급)를 수령
- 회계적으로는 마진이 맞음 → 고객이 알게 되면 신뢰 붕괴 리스크
- 공정거래법상 **"끼워팔기(tying)"** 또는 **"필수품목 강제"** 이슈로 해석될 여지

### 2.4 가맹사업법 리스크 (가장 큰 법적 위험)
- 다수 점주에게 **표준화된 상품·서비스·인테리어를 일괄 공급**하면 법적으로 **"가맹본부(프랜차이저)"** 로 분류될 수 있음
- 정보공개서 등록 의무, 가맹금 반환, 필수품목 공시 의무 발생
- 콤마나인이 의도치 않게 **프랜차이즈 본사 책임**을 지게 될 가능성

### 2.5 협력사 의존도 = No Moat
- 배민·정수기 업체가 수수료 조건을 일방적으로 변경 시 수익구조 붕괴
- 협력사가 고객 DB 확보 후 직접 거래로 전환할 인센티브 존재
- **계약상 락인(Lock-in) 장치가 없으면** 협상력을 빠르게 상실

### 2.6 운영 복잡도 폭증
- 인테리어 + 인터넷 + 카드 + 정수기 + 배민 + 광고 = **6~7개 도메인 동시 관리**
- 한 영업사원이 모두 다루려면 전문성 부족, 분업하면 인건비 증가
- CS 사고 발생 시 책임소재 분쟁 (예: 정수기 고장도 콤마나인에 클레임)

## 3. 해외 유사 모델 분석

### 3.1 유사 모델 존재 여부
**"토털 패키지" 모델은 해외에도 존재하지만, 순수한 형태는 드뭄**

| 사례 | 국가 | 핵심 차이 |
|---|---|---|
| Toast | 미국 | POS+결제+급여+자본 번들. **인테리어는 안 함** |
| Square for Restaurants | 미국 | 결제+POS+배달 번들 |
| Sysco / US Foods | 미국 | 식자재 중심, 장비 리스 부가 |
| Restaurant Depot | 미국 | B2B 식자재·장비 |
| WeWork Food Labs | 미국 | 공간+인프라 번들 → **대실패** |
| 이디야·메가커피·더본코리아 | 한국 | **이미 동일한 구조**(브랜드 가맹점) |

### 3.2 왜 "인테리어 중심 토털 패키지"는 해외에 드문가?
1. **인테리어는 1회성 프로젝트** → 반복 매출 회수 모델과 궁합 불일치
2. **F&B 폐업률**이 LTV를 망가뜨림 → 자본회수 리스크
3. **반독점/공정거래법** 으로 끼워팔기가 강하게 규제됨 (EU·미국)
4. **인테리어는 지역밀착 산업** → 표준화·규모화 어려움
5. **결국 프랜차이즈 본사 형태로 수렴** → 별도 모델로 존재할 이유 약함

### 3.3 결론
> "없으니까 블루오션"이 아니라, **"이미 프랜차이즈 본사 모델로 흡수되어 있다"** 가 더 정확한 해석

## 4. 인지편향 점검 ("새로운 것 = 좋은 것" 오류)

| 항목 | 평가 |
|---|---|
| 진짜 새로운가? | **부분적**. 한국 프랜차이즈 본사가 이미 유사하게 운영 중 |
| 작은 차별점을 크게 본 것 아닌가? | **그럴 위험 있음**. "쇼룸 투어"는 신뢰 장치일 뿐 본질적 차별성 아님 |
| 미끼상품 + 부가수익 구조의 신규성? | **이미 검증된 패턴**. 통신사 보조금, 정수기 렌탈, 복합기 리스 모두 동일 |

> 본질적 신규성은 **"철제가구 제조사가 인테리어 통합으로 진입"** 이라는 진입각도이지, 비즈니스 모델 자체는 아님.

## 5. 보강 방안

### A. 재무 모델 우선 작성
- 점주 1명당 인테리어 손실 vs 월 적립 × 평균 생존기간 시뮬레이션
- **손익분기 점주수 / 회수 기간 명확화**
- 폐업률 50%를 반영한 **Stress Test**

### B. 락인 장치 설계
- 인테리어 할인 조건으로 **3~5년 인프라 서비스 계약** 명문화
- 중도 해지 시 인테리어 차액 회수 조항 (가맹사업법 위반 회피 필요)

### C. 법적 리스크 사전 차단
- **가맹사업법 적용 여부** 변호사 검토 필수
- 공정거래법 끼워팔기·필수품목 강제 조항 검토
- 협력사 수수료(0.5%) 공시 정책 결정

### D. 협력사 협상력 확보
- 단순 소개가 아닌 **독점 채널 계약** 시도
- 협력사가 우리를 우회 못하도록 **고객 계약 주체를 콤마나인**으로 설정

### E. "쇼룸 = 신뢰" 가설 검증
- 영천 사옥 방문이 계약 전환율을 얼마나 올리는지 **파일럿 측정**
- 직관에 의존하지 말고 A/B 테스트

### F. 타겟 세그먼트 좁히기
- 모든 창업자가 아니라 **생존율 높은 업종**(편의점, 무인매장, 카페 등) 우선
- 폐업률 높은 일반 음식점은 후순위

## 6. 최종 결론

**한 줄 평**
> "혁신적 신규 모델"이라기보다는 **"제조업체가 한국 프랜차이즈 본사 모델의 일부를 차용한 진입 전략"** 에 가까움

**가능성**
작동 가능. 다만 다음 4가지가 갖춰지지 않으면 3~5년 후 자본잠식 위험 큼:
1. 재무 시뮬레이션
2. 법적 검토
3. 락인 계약
4. 폐업률 헤지

**우선 실행 과제 (Top 4)**
1. 점주 1명 단위경제 모델 엑셀 작성
2. 가맹사업법 변호사 자문
3. 협력사 1곳과 락인 계약 시범 체결
4. 쇼룸 투어 전환율 파일럿 측정

**프레이밍 권고**
> "이거 새로운 거니까 좋다" ❌
> **"이미 존재하는 패턴인데, 우리가 더 잘할 수 있는 이유는 X다"** ✅

## 7. 회의 발표용 핵심 메시지 (5줄 요약)

1. 본 모델은 **"한국 프랜차이즈 본사 모델"의 변형**이며, 인테리어 진입각도가 차별점이다.
2. **인테리어 30~40% 할인**은 업계 평균 마진을 초과하므로 회수 시뮬레이션이 필수다.
3. **F&B 3년 폐업률 50~60%** 가 본 모델의 가장 큰 LTV 리스크다.
4. **가맹사업법·공정거래법** 검토 없이 확장하면 의도치 않게 프랜차이즈 본사 책임을 지게 된다.
5. 실행 전 **단위경제 모델 + 법률 자문 + 락인 계약 + 쇼룸 효과 측정** 4개 검증을 선행해야 한다.
