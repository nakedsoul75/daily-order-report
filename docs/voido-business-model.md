# Voido 신규 비즈니스 모델 분석 (통합본 v2)

> 작성일: 2026-05-19
> 작성 목적: 회의 발표용 자료 / 비즈니스 모델 타당성 검증 + 확장 전략
> 작성자: 콤마나인

---

## 0. 한 줄 정의

**"강제성 없는 어필리에이트 + 자체 제조 원가 우위 + 점주 풀 기반 협상력 플라이휠"**
- 한국 프랜차이즈 본사 모델의 검증된 패턴을 **강제성 없이** 차용한 변형
- 인테리어 = 창업 시발점 진입점, 협력사 영업력 = 확장 엔진
- 자체 영업조직 없이도 **협력사 영업조직 외주화**로 스케일링

---

## 1. 비즈니스 모델 구조

### 1.1 진입 전략 (미끼상품)
- Voido 자체 제작 가구·제품을 마진 최소화로 제공 ("채소공장 마진까지 뺀다")
- 인테리어 시공가: 1,000만원 → **600~700만원** (30~40% 할인)
- 창업의 시발점에 선진입하여 토털 패키지로 후속 매출 연동

### 1.2 마진 구조 재설계 (핵심)
| 사업 라인 | 기존 마진 전략 | 신규 마진 전략 |
|---|---|---|
| **팩토리나인** (자체 제조) | 정상 마진 | **이익 보존** (원가 우위 유지) |
| **DL (Direct Line) 판매** | 100% 마진 확보 | **20~30%만 잡음** |
| **인프라 수수료** | 0% | 0.5%~1% 누적 적립 |

**핵심 논리**: 시장 자체에 거품이 많으므로, 우리가 마진을 양보해도 **시장 평균 이하 가격**을 만들 수 있고, 양보분은 **점주 혜택 + 파이 확대**로 전환

### 1.3 인프라 수익원 (점주 1명당 추정)
| 항목 | 수익 구조 | 월 예상 |
|---|---|---|
| 카드 단말기 | 거래액의 0.0X% × 수년 | 매출 5천만원 기준 월 2~5만원 |
| 인터넷 구독 | 계약 수수료 + 월 리베이트 | 월 1~2만원 |
| 정수기 | 0.5% × 렌탈료 | 월 1천~3천원 |
| 테이블오더 | 설치 + 월 사용료 리베이트 | 월 1~3만원 |
| 배민 광고/깃발 | 광고비 % | 월 2~5만원 |
| **합계** | | **월 6~16만원** |

→ 연 70~190만원 × 평균 3~5년 생존 = **누적 210~950만원**
→ 인테리어 할인 적자(300~400만원) **회수 가능** (상위 매출 점포 집중 시)

### 1.4 운영 분담 구조 (50:50)
- **콤마나인 (50%)**: 리드 발굴, 패키지 큐레이션, 점주 신뢰 확보
- **협력사 (50%)**: 실제 클로징, 설치, CS
- 예: 정수기 = 콤마나인은 계약 의사 확인만, 정수기 업체가 직접 방문해 클로징
- → 콤마나인은 **B2B 어필리에이트 포지션**, 인건비·전문성 부담 최소화

### 1.5 영업 조직 외주화 (핵심 혁신)
**문제**: 콤마나인은 개발·마케팅 중심으로 자체 영업조직이 작음

**해결**:
- 배민·정수기·POS·로봇·인터넷 등 각 분야 **기존 영업조직 활용**
- 콤마나인은 "창업 시발점 접점" 가치를 제공 → 협력사가 **자발적으로 합류**
- **지역 영업맨 포섭**: 각 지역 우수 영업맨에게 수수료 룰 설계 후 파트너 계약
- 협력사·지역 영업맨이 **스스로 추가 영업 수행** → 콤마나인 영업력 레버리지 ↑

**결과**: 자체 영업조직 채용·운영 비용 0원으로 다채널 영업망 구축

### 1.6 신뢰 구축 장치
- 영천 창대 사옥 = **실물 쇼룸**
- 사옥 투어를 통한 실체 있는 회사 증명
- "왜 이렇게 싸게 해주지?" 의심 차단
- **선택 옵션 보장**: "의심스러우면 우리거 안 해도 된다" → 강제성 제거

## 2. 핵심 강점

### 2.1 자원 효율성 (가장 큰 강점)
- 자체 영업조직 0원 → **개발·마케팅에 집중 가능**
- 협력사·지역 영업맨이 영업 수행
- 콤마나인은 **접점 큐레이션**만 담당
- 소기업이 대기업 모델을 모방 가능한 구조

### 2.2 검증된 패턴 (이미 성공한 방정식)
- 한국 프랜차이즈 본사 모델 = **이미 작동 확인된 구조**
- 신규 시장 개척 리스크 없음
- 강제성 제거로 가맹사업법 회피 시도 가능

### 2.3 자체 제조 원가 우위 (모방 불가능)
- 철제가구 자체 제조 = 경쟁사 모방 불가
- 팩토리나인 이익 보존 + DL 마진 양보 = 시장 가격 파괴 가능
- 이 부분이 콤마나인만의 **진짜 해자(moat)**

### 2.4 플라이휠 효과 (점주 풀 기반 협상력)
```
점주 풀 확보 → 대기업 직접 채널 개설 → 수수료율 인상
       ↑                                        ↓
역인바운드 영업 유치 ← 시장 소문 ← 더 좋은 가격으로 점주 유치
```
- **초기**: 협력사 마진의 0.5% (을 입장)
- **중기**: 점주 30~100명 → 0.7% 협상 가능
- **장기**: 점주 100명 이상 → **1% 이상 + 대기업 직접 코드 발급**
- **궁극**: 배민·로봇업체·POS업체가 **먼저 찾아오는** 인바운드 구조

### 2.5 토털 패키지 = 진입 시점 선점
- 인테리어 = 모든 창업의 시발점
- 인테리어 완공 후 영업 ❌ → **처음부터 토털 패키지로 접근** ✅
- 제공 범위·선택권·가격 결정권을 콤마나인이 보유

## 3. 단계별 성장 로드맵 (대구 → 전국)

### Phase 1: 지역 검증 (대구·경북)
- **거점**: 영천 창대 사옥
- **점주 수**: 1~30명
- **수수료**: 0.5% (협력사 표준)
- **목표**: 모델 유효성 검증, 단위경제 확정
- **KPI**: 점주 1명당 누적 수익, 폐업률, 회수기간

### Phase 2: 광역 확장
- **지역**: 영남권 → 수도권 진출 검토
- **점주 수**: 30~100명
- **수수료**: 0.5% → **0.7% 협상 시작**
- **신규 활동**:
  - 지역 영업맨 네트워크 구축 (각 광역시별 1~2명)
  - 대기업과 직접 코드 발급 협상 시작
  - 자체 브랜드 인지도 마케팅
- **KPI**: 지역 영업맨 활성도, 협력사 수수료율 변동

### Phase 3: 전국 프랜차이즈 전문점
- **지역**: 전국
- **점주 수**: 100명 이상
- **수수료**: **1% 이상** + 대기업 직접 코드 발급 완료
- **신규 활동**:
  - 역인바운드 영업 유치 (배민·로봇·POS 등이 먼저 접근)
  - **프랜차이즈 전문점** 형태로 정형화
  - 점주 풀 자산화 (데이터·구매력 활용)
- **KPI**: 인바운드 영업 제안 건수, 코드 직접 발급 비율

## 4. 남아있는 리스크 및 대응

### 4.1 F&B 폐업률 (3년 내 50~60%)
- 카드·정수기 등 수수료가 점주 매출 연동
- 폐업 시 회수 즉시 중단
- **대응**:
  - 생존율 높은 업종 우선 (편의점, 무인매장, 카페, 기성 프랜차이즈 가맹점)
  - 일반 음식점은 후순위 / 조건부 진입

### 4.2 가맹사업법 회색지대
- 강제성 없어도 표준화 + 다수 점주 = 법적 다툼 여지
- 사옥 투어를 "브랜드 신뢰" 마케팅으로 쓸수록 가맹본사처럼 보일 수 있음
- **대응**:
  - 변호사 1회 자문 (비용 50~100만원)
  - 계약서·세일즈 스크립트에 "옵션 선택, 거절 시 가격 동일" 명시
  - 영업 교육 SOP 필수

### 4.3 임계점 전 Death Valley
- 점주 100명 미만 구간: 수수료 0.5% 그대로
- 이 구간에서 인테리어 할인 적자 발생
- **대응**:
  - 초기 자본 확보 또는 적자 감수 기간(2~3년) 명시
  - Phase 1에서 폐업률 낮은 업종 집중으로 자본효율 극대화

### 4.4 협력사 의존도
- 협력사가 수수료 조건을 일방 변경 시 수익 흔들림
- **대응**:
  - 초기부터 2~3개 협력사 복수 확보 (단일 의존 회피)
  - 점주 풀 100명 돌파 후 대기업 직접 코드로 전환

### 4.5 지역 영업맨 인센티브 설계
- 영업맨 합류 시 수수료 분배 → 콤마나인 마진 추가 축소
- **대응**:
  - 수수료 룰 명확화 (예: 신규 점주 발굴 영업맨 = 첫 12개월 50%, 이후 20%)
  - 영업맨이 점주를 직접 빼가지 못하도록 **고객 계약 주체를 콤마나인**으로 설정

### 4.6 "검증된 패턴"의 양면성
- 누구나 따라할 수 있음
- **차별화 카드 (3대)**:
  1. **자체 제조 원가 우위** (팩토리나인) ← 가장 강함
  2. **영천 실물 쇼룸**
  3. **지역(영남권) 선점**
- → 마케팅 메시지는 이 3가지에 집중

## 5. 해외 유사 모델 분석

### 5.1 유사 사례
| 사례 | 국가 | 핵심 차이 |
|---|---|---|
| Toast | 미국 | POS+결제+급여+자본 번들. 인테리어는 안 함 |
| Square for Restaurants | 미국 | 결제+POS+배달 번들 |
| Sysco / US Foods | 미국 | 식자재 중심, 장비 리스 부가 |
| WeWork Food Labs | 미국 | 공간+인프라 번들 → 대실패 |
| 이디야·메가커피·더본코리아 | 한국 | **동일 구조, 단 강제성 있음** (가맹) |

### 5.2 왜 "강제성 없는 인테리어 중심 토털 패키지"는 드문가?
1. 인테리어는 1회성 → 반복 매출 모델과 궁합 안 맞음
2. F&B 폐업률이 LTV 파괴
3. 반독점법 (특히 EU·미국)으로 끼워팔기 규제
4. 인테리어는 지역밀착 산업 → 표준화 어려움
5. 결국 프랜차이즈 본사로 수렴 (가맹사업법 진입)

### 5.3 결론
> "없으니까 블루오션"이 아니라, 콤마나인의 모델은 **"강제성 없는 옵셔널 구조 + 자체 제조 원가 우위"** 라는 한국 시장 맞춤형 변형이 가능하기에 **틈새가 있는 영역**임.

## 6. 우선 실행 과제

### 단기 (1~3개월)
1. 점주 1명 **단위경제 모델 엑셀 작성**
   - 시나리오: 매출 3천/5천/1억 × 생존기간 1년/3년/5년
2. **가맹사업법 변호사 자문** (1회)
3. **DL 라인 마진 재산정 시뮬레이션** (20~30% 시 손익)
4. 협력사 1곳과 **락인 계약 시범 체결** (정수기 또는 카드사)

### 중기 (3~6개월)
5. **쇼룸 투어 전환율 파일럿 측정** (A/B 테스트)
6. 영업 SOP·계약서·스크립트 표준화 (가맹사업법 회피 문구 포함)
7. **지역 영업맨 수수료 룰 설계 및 1~2명 영입**
8. 생존율 높은 업종 우선 타겟팅 리스트 작성

### 장기 (6~12개월)
9. Phase 1 종료 시점 KPI 점검 (점주 30명 목표)
10. 대기업 직접 코드 발급 협상 사전 자료 준비
11. **프랜차이즈 전문점 법적 구조 검토** (Phase 3 진입 대비)

## 7. 회의 발표용 핵심 메시지 (7줄)

1. 본 모델은 **"강제성 없는 한국 프랜차이즈 모델의 변형"** 이다. 새로워서 좋은 게 아니라 **이미 검증된 패턴**이라 좋다.
2. **자체 제조 원가 우위(팩토리나인) + 영천 실물 쇼룸 + 지역 선점** 의 3대 차별점이 콤마나인만의 해자(moat)다.
3. DL 라인 마진을 100% → 20~30%로 양보하지만, **시장 거품 회수 + 파이 확대**로 전환된다.
4. **자체 영업조직 없이** 협력사·지역 영업맨 네트워크를 활용해 영업력을 외주화한다.
5. **점주 100명 임계점 돌파** 시 협력사 협상력이 0.5% → 1% 이상으로 상승하고, **역인바운드 영업**이 들어오는 플라이휠이 작동한다.
6. F&B 3년 폐업률 50~60%·가맹사업법 회색지대·임계점 전 Death Valley 3대 리스크는 **법률 자문, 단위경제 모델, 초기 자본 계획**으로 대응한다.
7. Phase 1 대구·경북 → Phase 2 광역 → Phase 3 전국 프랜차이즈 전문점으로 **단계적 확장 로드맵**을 명시한다.

## 8. 최종 결론

**모델 작동 가능성**: ✅ 높음

**조건부**:
- 단위경제 시뮬레이션 + 법률 자문 + 락인 계약 + 폐업률 헤지 4가지 검증 선행
- 초기 Death Valley(점주 100명 도달 전 2~3년) 자본 계획 사전 마련
- 영업맨 수수료 룰 명확화로 채널 갈등 방지

**프레이밍**:
> ❌ "이거 새로운 거니까 좋다"
> ✅ "이미 검증된 패턴이고, 우리는 **자체 제조 + 실물 쇼룸 + 강제성 제거**라는 3가지 무기로 더 잘할 수 있다"
